# Star Spiral Art

Created by **Erion Nezha**.

Live demo: https://erionnezha.github.io/Star-Spiral-Art/

A hypnotic star spiral: 460 five-pointed stars, each rotated 145° and shifting hue, drawn on a black canvas. A faithful web port of the original Python turtle + colorsys script.

## Original Python

`star_spiral.py` runs with the Python standard library only (`turtle` and `colorsys` ship with Python):

```
python star_spiral.py
```

## Web version

Just open `index.html` in any browser — a single file, no dependencies, no build step. The drawing is recomputed and animated live on a full-viewport canvas.

## Provenance

Original script by Erion Nezha — web port added so it runs in the browser.
